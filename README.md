# 🌟 About The Project

**MahaTour** is a frontend tourism website designed to help users explore famous destinations, activities, and travel planning information related to Maharashtra.

The project focuses on:

- Modern UI/UX design
- Responsive layouts
- Interactive navigation
- Modal-based authentication UI
- Clean frontend structure

---

✅ Modern glassmorphism navbar  
✅ Responsive mobile navigation menu  
✅ Beautiful hero section

✅ Contact form UI
